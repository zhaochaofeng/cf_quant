# GP + LLM 量化因子挖掘

基于东吴证券《AI因子挖掘的双路径实践与Skill沉淀》中 LLM 增强遗传编程路线，在 DEAP + qlib 表达式因子挖掘框架上进行工程化升级。

## 设计目标

传统遗传编程（GP）能在表达式空间高效搜索，但随机交叉变异产生的因子往往缺乏金融解释、过拟合风险高。LLM 直接写因子具备逻辑性，但推理成本高、难以大规模批量探索。

本模块将两者优势结合：

- **GP** 负责高通量搜索、适应度评价、候选筛选
- **LLM** 提供金融逻辑约束：子表达式基因提取、周期性候选注入、进化总结

共同目标不是让 AI 偶然写出几个有效因子，而是构建能够持续生成、评估、修正、筛选和沉淀因子的研究流程。

## 方法论

### LLM 增强遗传编程核心机制

**1. 子表达式基因（Sub-expression Genes）**

LLM 从初始优质因子（如 Alpha158）中提取可复用的子表达式，每个子表达式对应具体的金融行为：

- `bearish_reversal_flag`：高开阴线形态，刻画隔夜情绪释放后的反转压力
- `volume_surge_squared`：相对历史均值的超额放量非线性强化，捕捉天量异动
- `overnight_intraday_vol_ratio`：隔夜与日内波动率比值，识别价格波动驱动来源

这些基因作为终端注册到表达式树空间，使 GP 搜索从"随机组合算子"转变为"在金融含义构件之上进行组合"。

**2. 分岛进化（Island Model）**

多个岛屿独立进化，每 N 代进行岛间个体迁移（环形拓扑）。分岛结构增加搜索多样性，避免种群过早收敛于局部最优。

**3. 周期性 LLM 注入**

每隔 M 代，LLM 读取各岛屿当前最优表达式，分析有效结构与失败模式，为每岛生成新候选因子。新因子需经竞争替换：仅当其适应度优于岛内底部个体时才进入种群，确保 LLM 只贡献真正有价值的基因。

**4. 双层评价体系**

- Layer 1（有效性检查）：表达式语法合法性 → qlib 可计算性 → 截面区分度(因子值相同则无区分度)
- Layer 2（预测能力评价）：训练集 RankIC + ICIR + 表达式复杂度惩罚

适应度函数仅使用训练集数据，测试集在进化完成后统一评估，规避样本内过拟合。

**5. 低相关筛选**

进化结束后，按测试集 RankIC 降序进行贪心筛选：逐个检查与已选因子的最大相关性，低于阈值则保留。确保因子库内部差异化，避免坍缩为少数同质化信号。

## 系统架构

```
data/factor_gp/
├── run.py          # [已有] 单种群验证 Demo，保留作为基线
├── conf.py         # 全局配置（数据区间、GP 参数、筛选参数），避免与项目根 config.py 冲突
├── primitives.py   # 算子注册中心：基础终端 + 算子 + 子表达式基因
├── evaluate.py     # 因子评估器：双层评价 + 共享缓存 + 无效表达式记录
├── evolution.py    # 分岛进化引擎：多岛独立进化 + 迁移 + LLM 注入
├── llm.py          # LLM 接口层：子表达式基因提取 + 周期性候选生成
├── screening.py    # 后处理：测试集评估 + 低相关筛选
└── pipeline.py     # 主流水线：串联全部阶段 + 断点恢复
```

### 数据流

```
Phase 0: 初始化
  qlib.init() → 加载行情数据 → 构建初始 pset（基础算子 + 终端）

Phase 1: LLM 子表达式基因提取
  加载初始优质因子 → LLM 提取可复用子表达式 → 注册为 pset 终端

Phase 2: 分岛进化（核心循环）
  各岛独立进化一代 → 岛间迁移（每 N 代）→ LLM 注入（每 M 代）
  → 收集所有岛屿候选因子

Phase 3: 后处理
  测试集评估 → 低相关筛选 → 生成报告
```

### 关键设计决策

**子表达式基因作为终端而非算子。** 避免 DEAP 强类型系统的 arity 匹配复杂度。终端（叶子节点）在交叉变异时自然替换，无需额外类型约束。

**LLM 生成竞争替换而非直接注入。** LLM 生成的表达式不一定有效或有用。先评估再竞争替换，确保 LLM 只贡献真正有价值的基因。

**跨岛共享评估缓存。** 所有岛屿使用同一个 FactorEvaluator 实例，表达式→适应度的映射全局共享，避免重复计算。

**不修改 run.py。** 保留原始 Demo 作为基线对比，所有新功能在独立模块中构建。

## 评价体系

### 核心指标

| 指标 | 计算方法 | 用途 |
|---|---|---|
| RankIC | 每期截面 Spearman 秩相关系数均值 | 衡量因子方向一致性 |
| ICIR | RankIC 均值 / RankIC 标准差 | 衡量因子稳定性 |
| RankIC 衰减 | 训练集 IC − 测试集 IC | 衡量过拟合程度 |
| 因子相关性 | 因子值截面 Spearman 相关系数 | 衡量差异化程度 |

### 适应度函数

适应度仅使用训练集数据，组合三项：

- |RankIC_train|：绝对预测能力
- ICIR_train：预测稳定性
- 表达式深度惩罚：抑制过复杂结构

## 配置参数

核心可调参数及报告推荐值：

| 参数 | 推荐值 | 含义 |
|---|---|---|
| n_islands | 3 | 岛屿数量 |
| n_pop | 600 | 每岛种群大小（总 1800） |
| n_gen | 20 | 进化代数 |
| migration_freq | 4 | 岛间迁移间隔（代） |
| llm_inject_freq | 3 | LLM 注入间隔（代） |
| llm_inject_n | 5 | 每次每岛 LLM 生成数 |
| complexity_penalty | 0.005 | 表达式深度惩罚系数 |
| corr_threshold | 0.70 | 低相关筛选阈值 |
| train_end | 2022-12-31 | 训练/测试分割点 |
