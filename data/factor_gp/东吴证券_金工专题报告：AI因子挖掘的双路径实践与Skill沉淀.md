## 深度学习系列之三：AI 因子挖掘的双路径实践与 Skill 沉淀——从表达式搜索到 Agent化研究流程

本研究围绕AI因子研究中的“搜索能力”与“沉淀能力”展开：一方面将大语言模型的金融逻辑推理能力引入遗传编程搜索，另一方面让大语言模型在代码空间中生成因子并自主沉淀工具函数，最终进一步封装为可复用的选股因子迭代 Skill。传统量价因子研究通常依赖研究员人工提出假设、编写表达式并反复回测，研究效率和搜索广度均受到限制；而单纯依靠大语言模型直接生成因子，又面临推理成本较高、批量探索能力不足、历史反馈难以沉淀等问题。本文尝试从两个维度解决上述矛盾：第一，在表达式空间中引入 LLM 增强遗传编程，用大语言模型提供金融逻辑和子表达式基因，用遗传算法完成高强度搜索；第二，在函数空间中让 LLM 直接生成可运行的 Pandas/Numpy 因子函数，并通过历史反馈和工具函数库持续迭代。两条路线分别对应“可控表达式搜索”和“开放函数式生成”，共同目标并不是让 AI 机械地产生更多公式，而是让 AI 参与因子研究的完整链条：提出假设、生成信号、接受评测、吸收反馈，并将可复用经验沉淀下来。

LLM 增强遗传编程路线实现了大语言模型金融逻辑与遗传算法搜索能力的结合，在表达式空间中生成了 87 个候选量价因子。传统遗传编程可以在大规模表达式空间中快速搜索，但容易生成缺乏金融解释、结构复杂且过拟合风险较高的因子；LLM 直接写因子具备较强逻辑性，但难以低成本完成大规模批量探索。本文通过 LLM 提取子表达式基因、构建表达式树搜索空间、分岛进化、周期性 LLM 注入和低相关筛选等机制，将两者优势结合起来。实证结果显示，87 个候选表达式因子全区间|RankIC|均值约为 6.98%，全区间|ICIR|均值约为 0.79，测试集|RankIC均值约为 6.93%，表现较为稳定。相关性层面，约 81.6%的因子对内部相关性低于 0.70，约 91.2%的因子对低于 0.75；与 20 日反转、20 日波动率和 20 日平均换手率等传统量价因子相比，也保留了较明显差异。进一步相对 Alpha158MLP 进行双残差增量 IC 检验，87 个因子的平均增量 IC 约为 2.53%，说明其在常见量价综合信息之外仍能提供边际解释 力 。 LOWPOS_SHARPE_COV 、 CANDLE_SHADOW_P3 和RETCHG_MINUS_GAP 等代表因子表明，该路线能够在保持表达式可复现性的同时，挖掘出具有较清晰金融逻辑的量价结构。

## 1. 逻辑搜索与能力沉淀：AI 因子研究新范式

## 1.1. LLM写因子的能力与瓶颈

在前期报告《深度学习系列之一：AI重塑量化，基于大语言模型驱动的因子改进与情绪Alpha挖掘》中，我们已经验证，大语言模型具备较强的金融逻辑推理能力，能够围绕已有因子进行逻辑改写、结构增强和新因子构造，并在部分场景下获得较好的实证效果。这说明，LLM 并不只是代码补全工具，它已经能够阅读因子表达式，理解背后的金融含义，并从价格行为、成交量变化、情绪冲击和交易拥挤等角度提出新的构造思路。

不过，单纯依赖 LLM逐个生成因子也存在明显限制。一方面，LLM推理速度较慢，单次生成成本较高，不适合直接承担大规模暴力搜索；另一方面，单点式生成高度依赖提示词设计和上下文样例，难以形成稳定、可复用、可持续扩展的因子研究流程。相比之下，传统遗传算法能够在表达式空间中快速组合算子、变量和参数，适合高通量搜索，但其随机交叉和变异得到的表达式往往带有机械拼接特征，金融含义较弱，解释性不足，也更容易产生样本内过拟合。

## 1.2. 两条路线：表达式空间与代码空间

基于上述背景，本文尝试将 LLM 的金融逻辑推理能力与算法搜索能力结合起来，从“AI 写因子”进一步走向“AI 自动化因子研究”。核心目标不是让模型偶然写出几个有效因子，而是构建能够持续生成、评估、修正、筛选和沉淀因子的研究流程。

本文设计了两条低频量价因子自动挖掘路线。第一条是在标准化表达式空间中引入LLM，构建 LLM增强遗传编程因子挖掘框架：LLM从已有优质因子中提取子表达式基因，并在遗传编程进化过程中周期性生成具备金融逻辑的新个体；遗传编程则负责大规模搜索、适应度评价和低相关筛选。第二条是让 LLM 直接在代码空间中生成Pandas/Numpy 因子函数，构建 LLM 驱动的闭环式因子代码挖掘框架，通过执行反馈、错误修复、因子审查和工具函数沉淀，形成更接近真实研究员工作流的自动化因子研发过程。

## 1.3. 研究目标：构建可迭代的 AI 因子研究流程

因此，本文的主线不是单纯讨论“LLM能否写因子”，而是讨论 LLM能否参与因子研究的完整流程：从逻辑提炼、候选生成、代码实现，到报错修复、因子评估、知识沉淀和流程复用。前者强调在表达式空间中提升传统遗传算法的可解释性和金融逻辑约束，后者强调在代码空间中突破固定算子限制，表达更复杂的条件逻辑、状态切换、非对称衰减、回归残差以及隔夜与日内收益分解等研究员式因子构造方法。

## 2. 表达式空间：LLM增强遗传编程框架

## 2.1. 用金融逻辑约束进化搜索

第一条技术路线是在标准化表达式空间中引入 LLM，构建 LLM 增强遗传编程因子挖掘框架。传统遗传编程能够在表达式树空间中高效搜索，但其交叉、变异和选择主要由统计指标驱动，缺少对金融逻辑的理解。本文希望通过 LLM 为遗传编程提供更有含义的搜索材料和更具解释性的新个体，使表达式搜索从“随机组合算子”转向“有金融逻辑约束的进化搜索”。

在这一框架中，LLM并不直接替代遗传算法。遗传编程仍然负责高通量搜索、适应度评价和候选筛选；LLM则承担三类任务：一是从初始优质因子中提炼子表达式基因，二是在进化过程中总结优秀因子的共同结构，三是周期性生成新的候选表达式并注入种群。两者结合后，可以同时保留算法搜索的效率和LLM生成因子的可解释性。

## 2.2. 从子表达式基因到分岛进化

框架首先读取一组初始高质量量价因子，并由 LLM 从中提取可复用的子表达式。这些子表达式可以理解为“因子基因”，往往对应明确的量价结构，例如收益率、量能变化、K 线形态、价格位置、波动率、路径效率和量价协同关系。随后，系统将这些子表达式与基础算子共同注册到遗传编程的表达式树空间中，作为后续搜索的基本构件。

在进化阶段，算法采用分岛遗传编程结构。每个岛屿内部独立进行选择、交叉和变异，不同岛屿之间定期迁移优秀个体，以增加搜索多样性。每隔若干代，LLM会读取各个岛屿中当前表现较好的表达式，分析其有效结构与失败模式，并为每个岛屿生成新的候选因子。新因子需要经过语法校验、Qlib 计算和适应度评价，只有当其表现优于岛屿中的底部个体时才会进入种群。

候选表达式的评价分为两层。第一层是有效性检查，包括表达式语法是否成立、Qlib是否能够计算、横截面区分度是否足够等；第二层是预测能力评价，主要基于训练集RankIC、ICIR和表达式复杂度惩罚构建适应度。最终，系统从进化得到的候选因子中计算测试集表现，并结合因子间相关性进行低相关筛选。

## 2.4. 子表达式基因：把金融逻辑注入搜索空间

为了避免遗传编程完全依赖随机拼接，本文首先让 LLM 从已有优质因子中提取具有金融含义的子表达式基因。这些基因未必能够单独作为完整选股因子使用，但它们刻画了某类具体的交易行为或量价结构，可以作为后续表达式组合的基本部件。下面列举三个较有代表性的例子。

第一个例子是 bearish_reversal_flag，其表达式为：

Greater($open/Ref($close,1)-1,0)*Greater($open/$close-1,0) 

该基因刻画“高开阴线”形态：股票先以高于昨日收盘价的价格开盘，说明隔夜信息或开盘情绪较强；但随后日内价格走弱，收盘低于开盘，说明开盘后的买入力量未能维持，反而被卖压主导。这个结构通常对应短期情绪释放后的反转压力，适合作为过热反转类因子的构件。

第二个例子是 volume_surge_squared，其表达式为：

Power(Greater($volume/EMA($volume,{period})-1,0),2) 

该基因只关注相对历史均值的超额放量部分，并对其取平方。这样处理有两个作用：一是普通成交波动不会被过度放大，二是天量成交会被非线性强化。对于量价因子而言，极端放量往往比一般放量更能代表交易拥挤、资金冲击或情绪集中释放，因此该基因可以帮助后续表达式更敏感地捕捉异常量能事件。

第三个例子是 overnight_intraday_vol_ratio，其表达式为：

Std($open/Ref($close,1)-1,{period})/(Std($close/$open-1,{period})+1e-12) 

该基因比较隔夜收益波动和日内收益波动的相对大小。若该比值较高，说明股票近期价格变化更多来自隔夜信息冲击，例如公告、新闻或开盘前情绪；若该比值较低，则说明价格波动更多来自盘中交易博弈。这个基因不是直接判断股票好坏，而是帮助算法识别“价格波动由谁驱动”，从而为后续因子组合提供状态区分。

可以看到，LLM 提取的子表达式并不是无意义的中间变量，而是对应到具体的金融行为：高开后回落、天量异动、隔夜与日内波动来源差异。遗传编程随后在这些具有金融含义的基因之上进行组合搜索，从而在一定程度上缓解传统 GA表达式缺乏解释性的问题。

## 3.4. 传统因子相关性：继承与增量

为了判断新生成因子是否只是传统量价因子的简单变体，我们进一步计算其与传统反转、历史波动和换手等经典量价因子的相关性。结果显示，不同GA 因子与传统因子的相关性存在明显差异：部分因子与历史波动或反转因子相关性较高，说明其包含传统量价风险暴露；但也有部分因子在保持较高 IC 的同时，与传统因子相关性处于中等或较低水平，说明其可能提供了传统因子之外的结构信息。

## 4. 代表因子：从表达式到金融逻辑

为了进一步说明 LLM 增强遗传编程框架的可解释性，本节选取 3 个代表性因子进行拆解。相比只展示 IC结果，代表因子的意义在于说明：LLM+GA生成的表达式并非纯粹的统计拼接，而是可以还原到具体的交易行为、量价结构和金融机制。

## 4.1. LOWPOS_SHARPE_COV：平滑趋势中的质量动量

LOWPOS_SHARPE_COV 的表达式为：

$$
\text { Cov } (  \text { low } /   \text { close }, \text { EMA } (  \text { close } / \text { Ref } (  \text { close }, 1) - 1, \% d) / \text { Std } (  \text { close } / \text { Ref } (  \text { close }, 1) - 1, \% d), \% d)
$$

可以理解为两个子表达式基因的协同关系。前半部分$low/$close描述当日最低价相对收盘价的位置，值越高说明日内最低价离收盘价不远，下探幅度较小；后半部分是风险调整后的动量强度，即近期收益动量相对于自身波动的稳定程度。

从取值含义看，因子值较高通常意味着股票近期在动量变强的同时，日内下探并不深，价格路径更平滑，更像是稳步走强的趋势状态；因子值较低则往往意味着虽然可能存在上涨，但过程中震荡较大、回撤较深，趋势质量不高。因此，这个因子更适合被理解为“质量动量”，而不是单纯追逐过去涨幅的传统动量。

这一逻辑的关键在于，它并不奖励爆发式、情绪化的短期上涨，而是奖励“风险调整后动量改善，同时下行试探较少”的股票。换句话说，因子试图区分两类上涨：一种是路径平滑、回撤有限的趋势质量；另一种是波动剧烈、上冲下探都很明显的噪声型上涨。前者更可能代表稳定的资金推动，后者则更容易在短期内反复。

## 4.2. CANDLE_SHADOW_P3：上冲情绪后的短期反转

CANDLE_SHADOW_P3 的表达式为：

EMA(Power(Add(($close-$open)/$open,($high-Greater($open,$close))/$open),3),%d) 

其中，($close-$open)/$open 是实体涨跌幅，($high-Greater($open,$close))/$open 是上影线比例，两者相加后再取三次方，会显著放大极端K 线形态。因此，该因子本质上是在刻画“实体强弱+上冲幅度”的短期情绪极值。

从取值含义看，因子值较高通常意味着股票近期反复出现强上冲、长上影或情绪释放较猛的K线结构，属于“盘中很热、上探很剧烈”的状态；因子值较低则意味着近期更多是阴线实体较大、上探能力较弱，或者冲高后快速被压回的形态；因子值居中则说明K 线结构相对温和，没有明显极端上冲或极端弱势。

该因子的金融逻辑不是趋势跟随，而是短期过热后的反转。强上冲和长上影往往说明盘中买盘情绪较强，但也可能意味着上方抛压同步释放，资金在高位换手较为剧烈。实证上该因子RankIC为负，说明横截面上近期K线结构越亢奋、上冲情绪越重的股票，未来5天越容易回吐。因此，它更像是一个“短线情绪过热反转”信号。

## 4.3. RETCHG_MINUS_GAP：剔除跳空后的量价拥挤

RETCHG_MINUS_GAP 是本文更重点关注的代表因子。其表达式为：

$$
\begin{array}{l} \text { EMA(Sub(Mul(Sub(Div(\(close,Ref(\(close,1)),1),Sub(Div(\(volume,Ref(\(volume,1)),1)) ,Div(Sub(\(open,Ref(\(close,1)),Add(Ref(\(close,1),1e - 12))),\%d)} \end{array}
$$

表达式可以拆成两部分：第一部分是“收益率×成交量变化率”，刻画价格变化与成交量变化是否同向强化；第二部分是开盘价相对昨收的跳空幅度，用于刻画隔夜信息或开盘情绪冲击。因子用前者减去后者，再进行EMA平滑。

从取值含义看，因子值较高通常意味着股票近期存在较强的量价同向共振，但这种共振并不完全来自隔夜跳空，而更多发生在连续交易过程中。换句话说，它不是简单地捕捉“涨了且放量”，而是在剔除一部分隔夜跳空影响后，观察盘中交易形成的量价同步是否仍然强烈。因子值较低则可能意味着量价同步不强，或者价格变化更多由跳空驱动而非持续交易推动。

这一设计的金融含义在于区分两类价格上涨：一种上涨主要来自隔夜信息重估，例如公告、新闻或开盘前情绪；另一种上涨则来自盘中持续成交推动，表现为价格变化和成交量变化同步增强。后者如果过于强烈，往往意味着资金追逐集中、交易行为拥挤，短期内可能更容易出现获利了结或均值回归。因此，该因子虽然看似是量价共振结构，但实证上表现为负 IC，更接近“剔除跳空后的资金拥挤反转”信号。

从全区间表现看，RETCHG_MINUS_GAP 的 RankIC 为-7.44%，ICIR 为-0.9463；测试集 RankIC 为-7.48%，ICIR 为-0.7849，增量 IC 为 2.75%。与 3 个传统量价因子（20 日反转、20日低波、20 日低流动性）的相关性分别约为 39.1%、46.41%和 40.08%，整体处于中等水平，说明该因子并不是传统反转、波动或换手因子的简单替代，而是从“量价同步是否由持续交易推动”这一角度提供补充信息。

## 4.4. LLM赋能遗传算法：表达式空间的价值与边界

整体来看，LLM 增强遗传编程路线的核心价值在于，将传统遗传算法的高通量搜索能力与 LLM的金融逻辑理解能力结合起来。LLM提供可解释的子表达式基因和结构化生成能力，遗传编程负责在表达式空间中大规模组合、筛选和验证，两者共同缓解了传统GA表达式机械拼接、金融含义不足的问题。

从结果看，这一路线能够生成一批IC表现较强、样本外衰减有限、相对Alpha158MLP仍有增量信息的量价因子。代表因子也表明，LLM+GA 不只是复刻传统反转、波动或换手信号，而是能够进一步挖掘质量动量、短期情绪过热、剔除跳空后的盘中量价共振等更细的交易结构。

当然，这一路线仍然受到表达式空间和算子体系的约束。对于需要复杂条件判断、分组处理、回归残差、状态切换或更灵活数据处理的因子逻辑，固定Qlib 表达式并不总是足够。因此，下一部分我们进一步放宽表达式约束，讨论让 LLM直接在Pandas/Numpy代码空间中进行闭环式因子挖掘的第二条路线。

## 5. 代码空间：从预制函数到自生长工具库

## 5.1. 方法升级：从 AI 写代码到 AI 沉淀方法

在系列一报告中，我们已经尝试让 AI 直接基于 numpy 和 pandas 编写高频因子代码。相比“变量+算子”的固定组合模式，代码生成给予了AI更高的表达自由度，使其能够完成复杂的时序计算、截面处理和条件筛选。为了降低任务复杂度，当时我们预先封装了一组分域函数，用于识别分钟数据在横截面或历史同一时点中的高位、中位、低位区域，AI再基于这些预制工具构造高频因子。

本文第二条路线延续了这一思路，但做了两点升级。第一，研究对象从分钟级高频数据转向低频量价数据，目标是形成可用于选股的日频量价因子；第二，工具函数不再完全依赖研究员预先设计，而是在 AI 多轮生成因子的过程中逐步沉淀。也就是说，系列一更接近“人类预制工具、AI调用工具”，而本文希望进一步走向“AI生成因子、AI总结工具、AI再调用工具”的自生长研究框架。

## 5.2. 框架核心：生成因子，也生成研究组件

闭环式因子代码挖掘的核心目标，不只是让LLM多写几个 pandas因子，而是让模型在持续试错中积累可复用的研究组件。每一轮生成时，AI会参考可用数据字段、已有样例因子、历史因子表现，从已有有效逻辑出发继续扩展。生成完成后，系统会对因子进行统一评估，并将因子描述、实证表现和方向信息写入历史记录，作为后续生成的上下文。

在这个过程中，部分计算逻辑会反复出现，例如隔夜与日内收益分解、成交量状态识别、真实波幅刻画、成交量加权统计、滚动回归残差、状态切换信号和突破强度度量等。这些逻辑如果只停留在单个因子代码中，价值是局部的；一旦被抽象为工具函数，就会成为后续因子研究可以反复调用的方法资产。

因此，这条路线的关键不只是“代码空间更自由”，而是“代码空间可以沉淀知识”。AI每生成一批因子，就可能同时贡献新的因子候选和新的工具组件；工具组件再反过来提升下一轮生成的抽象层级，使模型不必每次都从最基础的数据运算开始，而可以在已有方法模块上继续组合和创新。

## 5.3. 研究闭环：经验输入、因子生成与工具沉淀

整个流程可以概括为三个环节。首先是经验输入，包括低频量价字段说明、样例因子代码、历史因子表现和表达式因子参考，使 AI 的生成建立在已有研究经验之上。其次是因子生成与评估，AI直接输出可计算的低频量价因子逻辑，系统统一计算 RankIC、

ICIR和因子方向，并记录到历史库中。最后是工具沉淀，当某些计算逻辑具有通用价值时，将其整理为工具函数，供后续生成继续调用。

这个闭环与传统自动化因子挖掘的区别在于，它不是单纯扩大搜索次数，也不是只把 LLM 当作代码生成器，而是把“生成结果”和“生成过程中的方法积累”同时纳入研究框架。对于低频量价因子而言，很多有效逻辑并不只体现在某个最终公式中，也体现在如何拆分收益、如何识别状态、如何度量量价共振、如何刻画交易拥挤等中间方法上。工具函数沉淀正是为了把这些中间方法保留下来。

## 5.4. 代表性工具函数：从计算模块到金融解释

为了说明工具函数沉淀并不是简单的代码复用，我们选取两个具有代表性的工具函数进行展示。它们本身未必直接构成完整选股因子，但能够把常见量价现象拆解为更清晰的金融结构，并在后续优秀因子的生成中被反复调用。

第一个工具函数是 decompose_overnight_intraday，用于将日收益拆分为隔夜收益和日内收益。隔夜收益更多反映公告、新闻、开盘前情绪和信息定价，日内收益则更多反映盘中交易博弈、资金承接和机构行为。通过这一拆分，AI可以进一步判断隔夜冲击是否被日内交易确认，或者是否在盘中被反向修正。

```python
Args:
    close: 后复权收盘价宽表
    open_price: 后复权开盘价宽表，需与 close 对齐

Returns:
    tuple: (overnight_ret, intraday_ret)
    - overnight_ret: 隔夜收益 = open_t / close_{t-1} - 1
    - intraday_ret: 日内收益 = close_t / open_t - 1

    """
    prev_close = close.shift(1)
    overnight_ret = open_price / prev_close - 1
    intraday_ret = close / open_price - 1
    return overnight_ret, intraday_ret
```

第二个工具函数是 classify_volume_regime，用于根据成交量相对历史中枢的状态，将交易环境划分为放量、缩量和正常体制。这个工具的意义在于，同样的价格行为在不同量能环境下可能具有不同含义：放量跳空可能代表信息驱动，缩量跳空则可能只是情绪扰动；放量下跌可能代表真实抛压，缩量下跌则可能更接近洗盘或流动性不足。

```python
def classify_volume_regime(volume: pd.DataFrame, window: int, high_threshold: float = 1.5, low_threshold: float = 0.6):
    """将成交量分类为放量/缩量/正常三种状态。

基于成交量与其 EMA 的比值进行状态判定，
适用于条件因子构建中的量能状态切换逻辑。

Args:
    volume: 成交量宽表 (index=trade_dt, columns=s_info_windcode)
    window: EMA 平滑窗口
    high_threshold: 放量阈值，vol/EMA > 此值判定为放量，默认 1.5
    low_threshold: 缩量阈值，vol/EMA < 此值判定为缩量，默认 0.6

Returns:
    tuple: (is_high_vol, is_low_vol, vol_ratio)
    - is_high_vol: 放量标记宽表 (0/1)
    - is_low_vol: 缩量标记宽表 (0/1)
    - vol_ratio: 成交量比率宽表 (volume / EMA)

    """
    vol_ema = volume.ewm(span=window).mean()
    vol_ratio = volume / (vol_ema + 1e-12)
    is_high_vol = (vol_ratio > high_threshold).astype(float)
    is_low_vol = (vol_ratio < low_threshold).astype(float)
    return is_high_vol, is_low_vol, vol_ratio
```

可以看到，工具函数沉淀的价值不只是减少重复代码，而是把可复用的金融判断模块保留下来。后续 AI 再生成因子时，可以在这些模块之上组合更复杂的逻辑，从而让因子构造从“单次生成”逐步升级为“方法积累”。

## 7. 代表因子：函数式路线中的交易行为刻画

第六章从整体层面展示了 80 个函数式因子的有效性、相关性和增量信息。本章进一步选取三个代表因子进行展开，重点观察函数式路线如何把低频量价数据组织成更细颗粒度的交易行为假设。与表达式因子相比，函数式因子的优势在于可以自然表达“先识别状态、再判断方向、最后做衰减累积”的多步骤逻辑，因此更适合刻画隔夜与日内、极值形成、量能体制切换等路径依赖特征。

## 7.1. 隔夜-日内修正：资金对隔夜情绪的再定价

第一个代表因子为 volume_weighted_intraday_reversal_persistence。该因子刻画“隔夜收益被日内交易纠正”的持续性，并用量比和换手率强化信息含量。具体而言，因子先将日收益拆分为隔夜收益和日内收益；当二者方向相反时，认为日内交易正在修正隔夜情绪。如果日内波动幅度足以覆盖隔夜波动，则视为更有效的修正，并给予更慢的衰减记忆；反之，则作为低质量修正，给予更快衰减。

```python
import pandas as pd
from toolkit import decompose_overnight_intraday, compute_volume_ratio

def volume_weighted_intraday_reversal_persistence(df: pd.DataFrame, vol_span: int = 20,
    fast_halflife: int = 3,
    slow_halflife: int = 12) -> pd.DataFrame:
    """日内对隔夜方向纠正的非对称衰减累积因子。"""
    close = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjclose')
    open_price = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjopen')
    volume = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjvolume')
    turn = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_freeturnover')

    # 分解隔夜与日内收益
    overnight_ret, intraday_ret = decompose_overnight_intraday(close, open_price)

    # 纠正标记：日内方向与隔夜方向相反（乘积为负）
    is_correction = (overnight_ret * intraday_ret < 0).astype(float)

    # 纠正强度：日内收益幅度（带符号，代表机构纠正方向）
    correction_signal = intraday_ret * is_correction

    # 纠正成功度：日内幅度超过隔夜幅度的比例，>1 表示完全纠正
    correction_ratio = (intraday_ret.abs() / (overnight_ret.abs() + 1e-8)) * is_correction
    is_effective = (correction_ratio > 1.0).astype(float)

    # 量比和换手率作为信息权重
    vol_ratio = compute_volume_ratio(volume, vol_span).clip(upper=5.0)
    turn_safe = turn.clip(lower=0.01)
    info_weight = vol_ratio * turn_safe
```

```python
# 有效纠正信号（日内完全覆盖隔夜）：慢衰减累积
effective_signal = correction_signal * is_effective * info_weight
slow_cum = effective_signal.ewm(halflife=slow_halflife).mean()

# 无效纠正信号（日内未能覆盖隔夜）：快衰减累积
ineffective_signal = correction_signal * (1.0 - is_effective) * is_correction * info_weight
fast_cum = ineffective_signal.ewm(halflife=fast_halflife).mean()

# 因子：有效纠正的慢累积 - 无效纠正的快累积
factor = slow_cum - fast_cum

return factor
```

从取值解读看，按选股方向调整后，因子值大通常意味着股票近期出现了较多“隔夜情绪被日内交易有效修正”的行为，且这种修正伴随较高成交活跃度，说明日内资金对隔夜消息或情绪定价有较强的再评估能力；因子值小则往往意味着隔夜冲击没有被有效消化，或者日内纠正更多是短暂、低质量、缺乏成交确认的波动。

从金融逻辑看，该因子更适合理解为“隔夜-日内行为分歧修正”信号。传统量价因子通常只看过去收益、波动或换手，而它进一步区分了隔夜定价和日内交易两类行为：隔夜更容易受消息和情绪影响，日内走势更能反映资金对隔夜冲击的再判断。若日内资金持续、放量地修正隔夜方向，说明市场正在重新定价，因子捕捉的是这种微观路径上的行为信息。

实证上，因子的RankIC 均值约为 5.39%，ICIR约为 0.80，方向为负。该结果说明，在成交活跃度确认、且修正行为具有持续性的情况下，股票未来收益的截面差异或将加大。

## 7.2. 极值形成过程：放量追高与恐慌出清的非对称

第二个代表因子为 volume_weighted_high_low_asymmetric_reversion。传统反转因子通常关注价格是否处在近期高位或低位，而该因子进一步关注近期高点和低点是如何形成的。因子识别过去 20 日内是否触及近期新高或新低：在创新高日，计算“量比×换手率×正收益”，用于刻画追高能量；在创新低日，计算“量比×换手率×下跌幅度”，用于刻画恐慌抛售能量。随后，因子对创新高信号做慢衰减，对创新低信号做快衰减，并结合当前价格在 20日高低区间中的相对位置。

```python
import pandas as pd
from toolkit import compute_volume_ratio

def volume_weighted_high_low_asymmetric_reversion(df: pd.DataFrame, lookback: int = 20,
    vol_span: int = 20,
    high_halflife: int = 10,
    low_halflife: int = 5) -> pd.DataFrame:
    """近期极值形成过程的量价结构非对称衰减因子。"""

close = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjclose')
high = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjhigh')
low = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjlow')
volume = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_adjvolume')
turn = df.pivot(index='trade_dt', columns='s_info_windcode', values='s_dq_freeturnover')

# 量比
vol_ratio = compute_volume_ratio(volume, vol_span)

# 滚动最高价和最低价
```

```python
rolling_max_high = high.rolling(lookback).max()
rolling_min_low = low.rolling(lookback).min()

# 当日是否创近期新高/新低（容差 0.1% 内视为触及）
is_near_high = (high >= rolling_max_high * 0.999).astype(float)
is_near_low = (low <= rolling_min_low * 1.001).astype(float)

# 创新高时的量价特征：量比 × 换手率 × 上涨幅度
ret = close.pct_change()
turn_safe = turn.clip(lower=0.01)

# 创新高日的信号强度：量比越大、换手越高、涨幅越大 → 追高能量越强
high_signal = is_near_high * vol_ratio.clip(upper=5.0) * turn_safe * ret.clip(lower=0)

# 创新低日的信号强度：量比越大、换手越高、跌幅越大 → 恐慌抛售越强
low_signal = is_near_low * vol_ratio.clip(upper=5.0) * turn_safe * (-ret).clip(lower=0)

# 非对称衰减：创新高信号慢衰减（追高后的回落压力持续久）
high_cum = high_signal.ewm(halflife=high_halflife).mean()

# 创新低信号快衰减（恐慌出清后修复快）
low_cum = low_signal.ewm(halflife=low_halflife).mean()

# 价格相对极值的位置（类 min20/close 思路，但加入量价过程信息）
price_position = (close - rolling_min_low) / (rolling_max_high - rolling_min_low + 1e-12)

# 最终因子：追高能量累积 - 恐慌出清能量累积，再乘以价格位置
# 高位（price_position 大）+ 追高能量强 → 因子值大 → 预期未来收益低
factor = (high_cum - low_cum) * price_position

return factor
```

从取值解读看，原始因子值大通常对应处在相对高位、且近期存在较强放量追高行为的股票。这类股票追高资金较拥挤，后续回落压力较大；原始因子值小通常意味着追高能量较弱，或者近期出现放量创新低后的恐慌出清，后续更容易出现修复。由于该因子方向为负，实证应用中更应关注原始因子值较低的一侧。

这一设计的核心在于，同样是价格接近极值，其后续含义取决于极值形成过程。放量、高换手、上涨创新高，往往说明追涨资金集中入场，短期交易拥挤，后续回落压力可能持续更久；放量、高换手、下跌创新低，则更可能对应恐慌抛售和筹码出清，修复速度可能更快。因此，该因子并非简单使用“高位反转、低位修复”的价格位置判断，而是把量能和换手所反映的交易拥挤程度纳入极值事件的解释。

实证上，因子的 RankIC 均值约为 6.97%，ICIR 约为 0.71，增量 IC 约为 2.51%，方向为负。该因子在 80 个函数式因子中表现靠前，说明“极值位置+极值形成质量+非对称衰减”这一组合逻辑能够提供较强的截面区分能力。

## 7.3. 量能体制切换：同一隔夜跳空在不同环境下含义不同

第三个代表因子为 overnight_gap_volume_persistence。该因子刻画隔夜跳空收益在不同量能体制下的持续性差异：先分解隔夜收益和日内收益，再用前一日成交量识别放量和缩量状态。放量体制下，隔夜跳空更可能来自机构或信息驱动，因此按动量逻辑累积；缩量体制下，隔夜跳空更可能是情绪或噪声驱动，因此按反转逻辑处理；最后再加入日内收益对隔夜跳空方向的确认或背离作为调制项。

```python
from toolkit import (
    decompose_overnight_intraday,
    classify_volume_regime,
    rolling_signed_power,
)

def overnight_gap_volume_persistence(df: pd.DataFrame, window: int = 20, vol_window: int = 20) -> pd.DataFrame
    """隔夜跳空在不同量能体制下的持续性差异因子。

    Args:
    df: 包含量价数据的长表
    window: EMA 平滑窗口，默认 20
    vol_window: 量能体制分类窗口，默认 20

    Returns:
    因子宽表 (index=trade_dt, columns=s_info_windcode)
    """
    def _pivot(col: str) -> pd.DataFrame:
    return df.pivot(index='trade_dt', columns='s_info_windcode', values=col)

    close = _pivot('s_dq_adjclose')
    open_p = _pivot('s_dq_adjopen')
    volume = _pivot('s_dq_adjvolume')
    turn = _pivot('s_dq_freeturnover')

    # 隔夜收益与日内收益分解
    overnight_ret, intraday_ret = decompose_overnight_intraday(close, open_p)

    # 量能体制分类（基于前一日成交量，避免未来数据）
    is_high_vol, is_low_vol, vol_ratio = classify_volume_regime(
    volume.shift(1), vol_window, high_threshold=1.3, low_threshold=0.7
    )

    # 隔夜跳空的平方根压缩（保留符号，压缩极端值）
    overnight_compressed = rolling_signed_power(overnight_ret, 0.6)

    # 换手率置信度权重（前一日换手率，避免未来数据）
    turn_weight = turn.shift(1).clip(lower=0.01, upper=20.0)

    # 放量体制下的隔夜跳空信号（机构定价，做动量）
    smart_overnight = overnight_compressed * is_high_vol * turn_weight * vol_ratio.clip(upper=4.0)

    # 缩量体制下的隔夜跳空信号（散户情绪，做反转，取负号）
    noise_overnight = -overnight_compressed * is_low_vol * turn_weight

    # 分别 EMA 累积
    smart_ema = smart_overnight.ewm(span=window).mean()
    noise_ema = noise_overnight.ewm(span=window).mean()

    # 日内收益对隔夜跳空的确认/背离（当日日内收益与隔夜跳空间同向=确认）
    confirmation = (intraday_ret * overnight_ret).clip(lower=-0.001, upper=0.001)
    confirm_ema = confirmation.ewm(span=window).mean()

    # 最终因子：放量隔夜动量 + 缩量隔夜反转 + 日内确认调制
    factor = smart_ema + noise_ema + confirm_ema * 10.0

return factor
```

从取值解读看，因子值大通常意味着股票近期的隔夜跳空更多发生在放量或较高置信度状态下，并且日内走势对隔夜方向有一定确认，说明隔夜定价可能具有信息含量和持续性；因子值小则往往意味着隔夜跳空更多出现在缩量或低置信度状态下，或者日内走势并不确认隔夜方向，说明隔夜价格变化更可能是情绪扰动，后续反转概率更高。

这个因子较好体现了函数式路线的表达优势。它并不简单认为跳空上涨就是利好、跳空下跌就是利空，而是先判断跳空发生在什么成交环境中，再判断盘中资金是否确认隔夜方向。同一个价格行为，在放量与缩量环境下可能对应完全不同的信息含义：放量跳空更像信息定价，缩量跳空则更像噪声冲击。

实证上，因子的 RankIC 均值约为 3.96%，ICIR 约为 0.69，增量 IC 约为 1.71%，方向为正。更值得关注的是，该因子与 20日反转、20日波动率、20 日平均换手率的相关性分别约为 6%、31%和 34%，与其他 79个函数式因子的最大相关性约为 34%，说明其信息来源相对独立。在量价因子普遍回撤的 2026 年，该因子的 RankIC 约为 3.75%，ICIR为 0.64，相较于全区间的均值水平无较大衰减，且多头超额和多空超额均为正，显示出较好的近期稳定性。

## 7.4. 从个例到框架：函数式路线的解释优势

三个代表因子共同说明，函数式路线的价值并不只是让 AI 写出更复杂的代码，而是让AI能够表达更接近交易过程的金融机制。隔夜-日内修正因子强调不同交易时段之间的定价分歧，极值形成因子强调价格位置背后的成交质量，隔夜跳空因子强调同一价格行为在不同量能体制下的含义切换。它们都不是对传统量价因子的简单放大，而是在基础量价变量之上加入了路径、状态和条件判断。

因此，函数式因子挖掘可以看作表达式空间路线的补充：表达式路线适合在受控搜索空间中高效寻找强信号，函数式路线则适合承载更具结构性的金融假设，并通过工具函数库沉淀为可复用的研究组件。二者结合后，AI因子挖掘既能够保持表达式因子的可解释性和搜索效率，也能够获得函数式因子的开放表达能力。

## 8. 总结与展望：从因子生成到研究能力沉淀

## 8.1. 两条路线的共同结论

本文围绕AI因子挖掘构建了两条互补路线：一条是LLM 增强遗传编程，在表达式空间中引入金融逻辑和进化搜索；另一条是函数式因子挖掘，让 LLM 直接生成可运行的低频量价因子函数，并在迭代过程中沉淀工具函数。二者的共同目标并不是让 AI 简单“写出更多因子”，而是让 AI具备更接近研究员的因子发现能力：能够提出假设、生成信号、接受实证反馈，并把可复用经验保留下来。

从实证结果看，两条路线均能够生成具有统计有效性和增量信息的量价因子。LLM增强遗传编程路线得到 87 个候选表达式因子，整体 RankIC 和 ICIR 表现较稳定，并且多数因子与传统量价因子、Alpha158MLP 合成因子之间保留一定差异。函数式路线得到80个低频量价因子，平均RankIC 约为 4.90%，平均 ICIR约为0.66，因子内部相关性和传统因子相关性整体处于中低水平，同时相对 Alpha158MLP 仍具有约 1.67%的平均增量 IC。

## 8.2. 表达式路线：在可控搜索空间中引入金融逻辑

LLM增强遗传编程的核心价值，在于把LLM的金融逻辑表达能力与遗传编程的搜索能力结合起来。传统遗传编程可以高效探索表达式空间，但生成结果容易缺乏金融解释，也更容易产生过拟合的复杂组合；LLM 直接写因子则具备较好逻辑性，但推理成本较高，难以大规模搜索。本文通过子表达式基因、分岛进化、LLM周期性注入和低相关筛选，将两者优势结合起来，使表达式搜索不再只是无约束的随机组合，而是带有一定金融先验的进化过程。

代表因子的分析也表明，表达式路线能够发现兼具可解释性和实证有效性的量价结构。例如，LOWPOS_SHARPE_COV 强调价格低点位置与平滑动量质量的协同，CANDLE_SHADOW_P3 刻画上冲情绪后的短期反转，RETCHG_MINUS_GAP 则剔除隔夜跳空后观察盘中量价拥挤。这些因子既保留了表达式形式的可复现性，又具有相对清晰的交易行为含义。

## 8.3. 函数式路线：把复杂交易行为写成可复用研究组件

函数式因子挖掘的价值，则在于打开了更自由的因子表达空间。相比固定表达式树，函数式路线允许 AI 分步骤描述金融机制：先拆分隔夜与日内收益，再识别量能体制；先判断极值是否形成，再区分极值背后的成交质量；先观察跳空方向，再判断盘中资金是否确认。这样的逻辑更接近人工研究员对市场微观路径的拆解，也更适合表达条件切

换、非对称衰减和状态依赖等复杂假设。

更 重 要 的 是 ， 函 数 式 路 线 不 仅 生 成 因 子 ， 也 沉 淀 研 究 工 具 。decompose_overnight_intraday、classify_volume_regime 等工具函数，将常见的量价研究判断封装为可复用模块，使后续因子生成能够站在已有计算组件之上继续探索。与系列一报告中预制分域函数不同，本文更进一步展示了工具函数在迭代过程中自动沉淀、被后续因子调用和复用的可能性。

## 8.4. 从报告到 Skill：通用因子迭代流程的产品化

除因子结果本身外，本文还将因子研究流程进一步整理为【东吴金工】选股因子迭代 Skill。需要强调的是，虽然本文实证案例聚焦低频量价数据，但该 Skill 本身并不局限于低频量价因子。它的核心输入是用户提供的数据、字段语义、评测目标和可选参考因子；只要数据能够被接入为DataFrame，并明确预测目标与评测口径，Skill就可以围绕相应数据生成可执行、可评测、可迭代的选股因子。换言之，低频量价只是本文展示的一种应用场景，未来也可以扩展到基本面、分析师预期、事件文本、高频交易行为或多源融合数据。

这个 Skill 不是对若干脚本的简单打包，而是把一次完整的因子研究过程封装成标准化工作流。流程从工作区启动或断点恢复开始，先确认研究工作区，再接入用户数据；随后逐步确认评测开始日期、结束日期、IC 口径、预测目标和参考因子，避免AI在数据语义和收益目标尚不清楚时直接生成代码。这样的设计把“先确认数据和目标，再生成因子”的研究纪律固化下来，使AI生成过程更可控、更可复盘。

更重要的是，Skill把“历史反馈”和“工具函数沉淀”纳入流程本身。每轮候选因子的名称、代码、评价指标、反馈和图表路径都会持久化记录，下一轮生成上下文会读取近期历史、当前工具库摘要和已有参考因子。若某个候选因子中出现可跨因子复用的计算逻辑，Skill 支持将其事务式合并到 toolkit.py 中；如果本轮执行失败，则恢复旧版本工具库，避免污染后续研究环境。

这使 Skill 具备了区别于普通提示词模板的价值：它不只是告诉 AI“请生成一个因子”，而是为 AI搭建了一个可持续积累的研究环境。随着迭代推进，系统会逐步沉淀有效因子、失败经验、工具函数和评价反馈。研究员可以在已有工作区中断点恢复，也可以接入新的数据和目标重新启动流程，从而把个人研究经验转化为团队可共享的研究资产。

因此，本文最终想强调的不只是“AI生成了多少个有效因子”，而是AI量化研究范式正在从结果生成走向流程沉淀。表达式路线和函数式路线提供了因子发现能力，Skill则把这种能力封装为可复盘、可继承、可共享的通用因子研究工作流。这也是 AIAgent在金融工程研究中更具长期价值的部分：它可以让研究能力本身被组织、传递和持续进化。

## 9. 风险提示

1) 模型失效风险。本研究基于历史行情数据、因子回测结果和历史样本中的统计规律进行分析，历史表现不代表未来收益。当市场微观结构、投资者行为模式、行业风格、流动性环境或监管政策发生显著变化时，历史有效的量价因子可能出现衰减甚至失效，导致因子组合表现不及预期。

2) 过拟合风险。本文使用大语言模型、遗传编程和函数式因子生成框架进行因子挖掘，尽管在研究中关注了样本外表现、因子相关性和增量 IC 等稳健性指标，但自动化生成方法仍可能在较大搜索空间中挖掘到偶然有效的历史模式。若未来市场环境与训练或回测样本差异较大，因子泛化能力可能下降。

3) 极端行情风险。在流动性危机、政策突发冲击、系统性风险爆发、市场交易机制调整等极端环境下，常规量价关系可能短期失效，因子信号可能无法及时识别风险，甚至给出与市场真实状态相反的信号，从而导致组合出现较大回撤。

4) 数据质量与评测口径风险。因子研究依赖底层行情、成交量、估值、复权价格、未来收益标签等数据输入。若原始数据存在缺失、异常、复权处理差异、停牌处理不一致或收益标签构造偏差，可能影响因子计算与评测结果。不同 IC 口径、调仓频率、股票池和样本区间设定也可能导致结论存在差异。

5) 大语言模型生成风险。大语言模型生成的因子逻辑、代码和工具函数可能存在理解偏差、实现错误、冗余计算或隐含假设。虽然本文通过自动执行、评测反馈、工具函数沉淀和人工复核降低相关风险，但在实际研究和投产前，仍需对因子代码、数据处理逻辑、收益对齐方式和异常值处理进行独立检查。

6) 交易成本与流动性风险。本文因子评价主要基于历史信号有效性和组合表现，实际交易中可能面临冲击成本、滑点、交易税费、涨跌停限制、停牌、成交不足等问题。对于换手率较高或偏小市值股票的策略，交易成本和流动性约束可能显著侵蚀回测收益，实盘表现可能低于历史测算结果。
